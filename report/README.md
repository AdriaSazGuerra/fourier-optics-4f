# 4f experimental design report

A privacy-cleaned PDF edition of the complete experimental design has been prepared for the portfolio. The student identifier has been removed and the cover displays **Adrià Saz Guerra**.

The report develops the 4f layout, magnification check, Fourier-plane localisation, diffraction-order measurements, low-pass cutoff, high-pass/band-pass/directional/notch filtering, progressive harmonic reconstruction, equipment budget and experimental limitations. It is an experimental design rather than a claim that every proposed measurement was performed.

The cleaned PDF is included in the downloadable portfolio bundle.
