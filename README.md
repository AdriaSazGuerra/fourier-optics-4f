# Fourier Optics: 4f Spatial-Filtering Experiment

Design of an experimental laboratory practical for coherent optical information processing with a **4f system**.

## Project objective

The experiment connects Fraunhofer diffraction, Fourier transforms and image formation by making the Fourier plane physically accessible and applying spatial filters to selected frequency components.

## Experimental design

- coherent, collimated **He–Ne source (λ = 632.8 nm)**
- object plane → first lens → Fourier plane → second lens → image plane
- quantitative validation of the transverse magnification `M = -f2/f1`
- measurement of diffraction-order positions for periodic objects
- variable-radius low-pass filtering with a predicted cut-off spatial frequency
- qualitative high-pass, band-pass, directional and notch filtering
- progressive reconstruction of a rectangular grating from selected harmonics

## Why it is interesting

A 4f system performs an optical Fourier transform and makes it possible to manipulate image information directly in spatial-frequency space. The proposed practical therefore acts as an experimental bridge between wave optics and signal processing.

## Report

The full project report contains the theoretical derivation, optical layout, experimental procedure, expected observations, equipment budget and discussion of limitations. It was designed as a new optics-laboratory practical at the Universitat Autònoma de Barcelona.
